Mesh-to-Mesh VFX Transition

Created a mesh-based VFX transition where one 3D mesh can transform into another using a real-time particle effect. Instead of simply hiding Mesh A and revealing Mesh B, the transition uses VFX particles to visually break apart the source object and reform the target object.

The workflow demonstrates how I can combine mesh data, particle behaviour, materials, animation timing, and real-time rendering to create a controlled transformation effect. The transition can be driven by parameters such as progress, particle movement, dissolve amount, scale, and timing.

This type of effect can be used for character transformations, object changes, teleportation, magical transitions, cinematic reveals, and other real-time presentation effects.

Unreal Engine VFX Experiment

🎯 Stencil-Based Ground Effect

Built a stencil-based ground effect to create the impression of depth without relying on a fully modelled 3D surface. A flat image is used as the visual base, while the stencil controls where the effect is revealed on the ground.

This approach allows a simple 2D image to read as a more dimensional surface by controlling the visible region, perspective, and layering of the effect directly in the material.

🔄 Tiling & Animated Texture

Used tiling texture coordinates and animated UV movement to keep the ground effect visually active. Rather than displaying a static image, the texture continuously moves and repeats across the surface to create the feeling of an evolving, living effect.

The tiling and movement can be adjusted through material parameters, allowing the speed, scale, and direction of the effect to be tuned without changing the underlying asset.

🎨 Toon Character Shader

Applied a toon-style character shader to give the character a stylized, graphic look that works consistently with the surrounding VFX and presentation. The shading uses controlled light and shadow transitions rather than relying only on smooth physically based shading.

This helps establish a cohesive visual language between the character, ground effect, and impact presentation while keeping the character readable during fast-moving VFX moments.

💥 HUD Impact Effect

Added a HUD-based impact effect to extend the visual feedback beyond the world-space VFX. Screen-space elements appear during the impact moment to reinforce the hit and make the action feel more immediate to the player.

Combining world-space effects with HUD feedback creates a layered presentation: the environment communicates the physical impact while the HUD communicates the intensity directly through the player's screen.

⚙️ Real-Time Material Control

The effect is designed around reusable material and VFX controls, allowing parameters such as texture scale, tiling, animation speed, reveal intensity, and impact timing to be adjusted during iteration.

Delivery process: start with a flat visual asset, define the stencil region that controls where the ground effect appears, then use tiled and animated texture coordinates to introduce motion. The effect is layered with additional VFX and a screen-space HUD impact treatment to create a stronger final presentation.
