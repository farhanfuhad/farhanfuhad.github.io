Project Overview

This project is a personal 5v5 mobile MOBA prototype developed in Unity. The work covers gameplay-facing systems and technical infrastructure required to support a networked mobile game.

The project is structured around reusable hero data, networked player entities, runtime asset loading, skills, UI, camera and movement, spawning/respawning, and mobile performance testing.

My Technical Involvement
🌐

Multiplayer Architecture

  • Implemented gameplay systems using Unity Netcode for GameObjects.
  • Worked with networked player entities and ownership-based behaviour.
  • Handled networked health, player state, spawning and gameplay interactions.
  • Structured systems so gameplay logic can run correctly in a multiplayer environment.
✨

Hero Skills

  • Built reusable SkillData definitions for different skill types.
  • Supported skill concepts including dash, projectile, AOE, buff, heal and targeted abilities.
  • Implemented cooldown, range, damage, duration and mana-related parameters.
  • Integrated skill input with the mobile skill UI.
📦

Addressables & Runtime Assets

  • Worked with Unity Addressables for runtime asset management.
  • Structured hero and gameplay content around reusable data and asset references.
  • Supported runtime loading of game content rather than relying only on direct scene references.
  • Explored workflows suitable for scalable multiplayer game content.
🕹️

Mobile Controls & Camera

  • Implemented mobile movement using a floating joystick workflow.
  • Developed third-person MOBA-style camera behaviour.
  • Worked on local hero targeting and camera follow behaviour.
  • Adjusted movement and camera response to achieve a responsive MOBA-style feel.
❤️

Health, Spawn & Match Flow

  • Implemented networked health using NetworkVariable-based state.
  • Worked on player spawn, team assignment, death and respawn workflows.
  • Structured match-level responsibilities around game management systems.
  • Supported blue/red team spawning and multiplayer match flow.
📱

Mobile Performance

  • Tested the prototype on Android mobile hardware.
  • Monitored draw calls, SetPass calls and rendering configuration.
  • Worked on render scale and camera/rendering setup for mobile performance.
  • Considered UI, minimap and rendering workloads when optimizing the project.
