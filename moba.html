Project Overview

This project is a 5v5 mobile MOBA prototype developed in Unity. The work covers gameplay-facing systems and technical infrastructure required to support a networked mobile game.

The project is structured around reusable hero data, networked player entities, runtime asset loading, skills, UI, camera and movement, spawning/respawning, and mobile performance testing.

My Technical Involvement
🌐

Multiplayer Architecture

  • Implemented gameplay systems using Unity Netcode for GameObjects.
  • Worked with networked player entities and ownership-based behaviour.
  • Handled networked health, player state, spawning and gameplay interactions.
  • Structured systems so gameplay logic can run correctly in a multiplayer environment.
🖥️

Local Multiplayer Test Server

  • Set up a local multiplayer server environment for regular gameplay testing.
  • Used the local server setup as a cost-effective alternative to relying on paid multiplayer server infrastructure during development.
  • Enabled frequent playtesting to reproduce bugs, validate networked gameplay and identify technical issues early.
  • Used repeated local multiplayer sessions to test gameplay systems and server/client behaviour during development.
⚙️

CI/CD Pipeline with Plastic SCM

  • Set up a CI/CD pipeline for the Unity project using Plastic SCM as the version control system.
  • Connected Plastic SCM source control with the Unity project build workflow for repeatable development builds.
  • Configured the CI/CD workflow to generate Android and iOS builds from the Unity project.
  • Automated parts of the build process to reduce reliance on manual builds and support faster iteration.
  • Used the pipeline to maintain a more consistent workflow for testing changes throughout development.
📦

Addressables & Runtime Assets

  • Worked with Unity Addressables for runtime asset management.
  • Structured hero and gameplay content around reusable data and asset references.
  • Supported runtime loading of game content rather than relying only on direct scene references.
  • Explored workflows suitable for scalable multiplayer game content.
🎨

Dynamic UI Atlas System

  • Developed a runtime Dynamic UI Atlas system to combine image assets into a shared atlas.
  • Designed the system so hero-related classes can request and register their required images into the atlas.
  • Centralized UI image management to reduce duplicated image handling across hero and gameplay UI.
  • Reduced UI draw calls by grouping related images into the atlas.
  • Balanced draw-call reduction against memory and loading cost, as a larger atlas can take additional time and memory to load.
  • Used the generated atlas for runtime UI presentation while keeping hero-specific content data-driven.
❤️

Health, Spawn & Match Flow

  • Implemented networked health using NetworkVariable-based state.
  • Worked on player spawn, team assignment, death and respawn workflows.
  • Structured match-level responsibilities around game management systems.
  • Supported blue/red team spawning and multiplayer match flow.
✨

VFX & Elemental Reaction System

  • Created real-time VFX for hero spawn and respawn sequences.
  • Developed death VFX to provide clear gameplay feedback when a hero is eliminated.
  • Implemented visual effects for an elemental reaction system, supporting different elemental interactions during gameplay.
  • Designed VFX to work within the mobile performance constraints of the project.
📱

Mobile Performance

  • Tested the prototype on Android mobile hardware.
  • Monitored draw calls, SetPass calls and rendering configuration.
  • Worked on render scale and camera/rendering setup for mobile performance.
  • Implemented a self-reporting performance system that captures a snapshot of the game when performance thresholds such as low FPS or high draw calls are detected.
  • Captured performance information alongside the snapshot to provide additional context for investigating device-specific issues.
  • Used the captured reports to identify problematic devices or scenes, investigate issues and guide optimization work.
  • Considered UI, minimap and rendering workloads when optimizing the project.
🛠️

Asset Validation Tool

  • Developed a Unity Editor tool accessible from the top Tools menu to scan game assets against predefined requirements.
  • Checked mesh requirements such as vertex and triangle counts.
  • Validated asset naming conventions and other Technical Art production requirements.
  • Displayed warnings for assets that did not follow the defined requirements, allowing issues to be identified before production use.
